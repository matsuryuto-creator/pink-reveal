# PINK REVEAL（画像が見えてくるブロック崩し）

スマホのブラウザで遊ぶブロック崩しです。ピンクのブロックを壊すと、下に敷いた自分の画像が少しずつ見えてきます。
`index.html` の1ファイルだけで動きます（外部CDN・ビルド不要）。選んだ画像は端末の中だけで使い、どこにも送信しません。

---

## 遊び方

1. 「画像を選ぶ」でカメラロールから画像を選ぶ（選ぶまでスタートは押せません）
2. 「ゲームスタート」
3. 画面のどこでも指を横にドラッグするとパドルが動きます（指の移動量に合わせて動く相対操作）
4. タップでボールを発射
5. 画面内のボールが0個になった瞬間にゲームオーバー（残機なし）
6. 全部壊すとクリア。「CLEAR!」が約3秒で消えて画像だけになります。**画面をタップすると**「もう一度」「タイトルへ」ボタンが出ます（ボタンのない場面で動画を締められるようにするため。ボタン以外をタップすると、また画像だけに戻ります）

### アイテム
| アイコン | 効果 |
|---|---|
| ×3 | 画面内のボールを3倍に増やす（🔥状態も引き継ぐ） |
| +3 | パドルから新しいボールを3個、扇状に発射 |
| 🔥 | 全ボールが貫通状態に。そのボールがパドルに当たると元に戻る（ブロックが80%以上残っているときだけ出る） |

### 設定（左上の ⚙）
- HUD表示 ON/OFF（撮影時に消したいとき用）
- 効果音 ON/OFF
- ボール速度（遅い／普通／速い）

設定はこの端末のブラウザに保存されます。設定を開いている間はゲームが一時停止します。

> **iPhoneの注意**：マナーモード（本体横のスイッチ）がONだと効果音が鳴らないことがあります。

## スマホで遊ぶ方法

### ① PCでサーバーを起動し、同じWi-Fiのスマホから開く（いちばん手軽）

1. PCのコマンドプロンプト（またはPowerShell）で、`index.html` があるフォルダへ移動します。
   ```
   cd （index.html があるフォルダのパス）
   ```
2. 次を実行します（Node.js が必要です。初回は「インストールしますか？」と聞かれたら `y`）。
   ```
   npx serve
   ```
3. 表示される `Network:  http://192.168.x.x:3000` のアドレスを、**PCと同じWi-Fiにつないだスマホ**のブラウザで開きます。
   - Windowsのファイアウォールの確認が出たら「プライベートネットワーク」を許可してください。
   - 開けないときは、スマホとPCが同じWi-Fiか（ゲスト用Wi-Fiは不可のことが多い）を確認してください。
4. 終わったらPC側で `Ctrl + C` を押すと止まります。

### ② GitHub Pages に置く（PCを起動しなくても遊べる）

1. GitHubで新しいリポジトリを作り、`index.html` をアップロードします。
2. リポジトリの **Settings → Pages** で「Branch: main / (root)」を選んで Save。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります。

**非公開（Private）リポジトリでの制約**
- 無料プランでは、**Private リポジトリから GitHub Pages は公開できません**（Pro / Team などの有料プランが必要）。
- 有料プランで Private リポジトリから公開しても、**Pagesのサイト自体は URL を知っている人なら誰でも見られます**（閲覧者を制限できるのは Enterprise Cloud のみ）。
- このゲームは画像をサーバーに送らないため、ページが見られても**あなたの画像が漏れることはありません**。気になる場合は、推測されにくいリポジトリ名にするか、①の方法を使ってください。

### デバッグモード
URLの末尾に `?debug=1` を付けると、右側にアイテム強制出現ボタン（×3 / +3 / 🔥）とFPS表示が出ます。
このとき、アイテム抽選を1000回シミュレーションした出現率がブラウザのコンソールに表示されます。

## 調整できる定数

`index.html` の `<script>` 冒頭にまとめてあります。数値を書き換えて保存し、ブラウザを再読み込みすれば反映されます。

| 定数 | 初期値 | 内容 |
|---|---|---|
| `BLOCK_COLS` | 10 | ブロックの列数 |
| `BLOCK_ROWS` | 14 | ブロックの行数 |
| `BLOCK_AREA_RATIO` | 0.6 | 画面のうちブロック領域が占める割合（上から） |
| `BLOCK_COLOR` | `#FF69B4` | ブロックの色（ボタンのピンクもこの色になります） |
| `BLOCK_BORDER_COLOR` | `#C2185B` | ブロックの枠線の色 |
| `BLOCK_HIGHLIGHT` | 白28% | ブロック上辺のハイライト |
| `BLOCK_SCORE` | 10 | 1ブロックの得点 |
| `ITEM_PROB_X3` | 0.2 | ×3 の確率 |
| `ITEM_PROB_P3` | 0.2 | +3 の確率 |
| `ITEM_PROB_FIRE` | 0.2 | 🔥 の確率 |
| `FIRE_MIN_REMAINING_RATIO` | 0.8 | 🔥が出るのに必要な残りブロックの割合 |
| `ITEM_FALL_SPEED` | 170 | アイテムの落下速度 |
| `MAX_BALLS` | 300 | ボール数の上限 |
| `BALL_SPEEDS` | 遅い300 / 普通420 / 速い560 | ボール速度（画面幅を360とした単位/秒） |
| `BALL_RADIUS` | 5 | ボールの半径 |
| `FIRE_COLOR` | `#FF8C1A` | 🔥ボールの色 |
| `X3_SPREAD_MIN_DEG` / `MAX_DEG` | 15 / 30 | ×3 で複製するときにずらす角度 |
| `P3_SPREAD_DEG` | 25 | +3 の扇の角度 |
| `PADDLE_WIDTH` | 76 | パドルの幅（画面幅=360） |
| `PADDLE_Y_RATIO` | 0.84 | パドルの縦位置（画面の上から84%） |
| `PADDLE_SENSITIVITY` | 1.0 | 指の移動量に対するパドルの動く量 |
| `MAX_BOUNCE_ANGLE_DEG` | 60 | パドルの端に当たったときの最大反射角 |
| `CLEAR_TEXT_DURATION` | 3.0 | 「CLEAR!」を表示する秒数 |
| `MAX_DPR` | 3 | 描画解像度の上限（重いときは 2 に下げる） |
| `MAX_IMAGE_SIDE` | 2048 | 読み込んだ画像を縮小する長辺の上限(px) |

### アイテム抽選の仕組み
ブロックを1つ壊すたびに `r = Math.random()` を**1回だけ**引きます。
- `r < 0.2` → ×3
- `0.2 ≤ r < 0.4` → +3
- `0.4 ≤ r < 0.6` かつ「壊した後の残りブロック数が初期数の80%以上（140個中112個以上）」→ 🔥
- それ以外 → なし

## 補足
- 画面は縦長スマホでは全面表示、横に広い画面（PCなど）では 9:16 の範囲に収めて表示します。
- HUD（スコア・ボール数・残りブロック率）は、TikTokの上部タブ・右側ボタン・下部キャプションと重ならないよう左上に小さく出しています。
